# v1.3 Release Notes — Documentation

This release officially publishes the v1.3 semantics across documentation.

## Key changes
- Request is **group-based only** (scope groups); no individual/subset request.
- Invite / Nominate are **individual-based** and **not scope-restricted**.
- `removed` is **inactive but reversible**.
- Re-entry occurs by **reactivating the same participant record** (no new participant rows; uniqueness preserved).
- If removed by **ORG**, re-entry requires **ORG reactivation** before user can accept.
- Removed users within scope may see a **rejoin / waiting** entry point.
